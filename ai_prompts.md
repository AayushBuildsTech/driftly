# Driftly Travels — Image Prompts (copy-paste ready)

Every prompt below is **complete** — just copy the grey box, paste it into your image
generator, download the result, and save it with the **"Save as"** filename into the
`public/images/` folder. Each prompt already includes the style, colours and aspect
ratio, so there is nothing to add.

**3 steps per image:**
1. Copy the prompt box → paste into Midjourney / DALL·E / Firefly / Leonardo / Flux.
2. Download the image, then compress to **WebP** at https://squoosh.app (keep it under
   the "Max size" listed — this keeps the site fast).
3. Save it in `public/images/` using the exact **"Save as"** name (lowercase, hyphens).

> Midjourney users: the `--ar` at the end of each prompt sets the shape automatically.
> Other tools: ignore `--ar` and just pick the matching aspect ratio in the app.

# BONUS — add a whole new destination with AI

Want a 4th destination (e.g. Vietnam, Maldives)? Paste the prompt below into any
chatbot (ChatGPT, Claude, Gemini), replace `<DESTINATION>` and `<N>`, then paste the
result as a new object inside **`lib/packages.ts`**. It instantly gets a detail page,
a home card and a downloadable PDF. Then generate its 7 images
(`<slug>-card`, `<slug>-hero`, `<slug>-gallery-1..5`) using the patterns above.

```
You are a luxury travel copywriter for "Driftly Travels", an Indian agency selling
premium international holidays (private transfers, 5-star stays, visa support,
upfront pricing). Create a package for <DESTINATION> lasting <N> nights.

Return ONLY a valid TypeScript object literal with EXACTLY these keys and types,
nothing else:

{
  id: string,                 // kebab-case slug, e.g. "vietnam-discovery"
  destination: string,        // e.g. "Vietnam"
  name: string,               // marketing name, e.g. "Vietnam Discovery"
  tagline: string,            // one short line
  duration: string,           // "<N> Nights / <N+1> Days"
  nights: number,
  days: number,
  priceFrom: number,          // realistic INR per person, whole rupees
  features: string[],         // 4 top selling points (for the card)
  image: string,              // "/images/<slug>-card.webp"
  imageAlt: string,
  heroImage: string,          // "/images/<slug>-hero.webp"
  heroImageAlt: string,
  overview: string,           // 2-3 warm sentences
  highlights: string[],       // 5-7 punchy bullets
  itinerary: { day: number, title: string, description: string, meals?: string, stay?: string }[],
  inclusions: string[],       // 6-8 items, flights first
  exclusions: string[],       // 3-5 items (visa, insurance, tips, add-ons)
  gallery: { src: string, alt: string }[],   // 5 items, src "/images/<slug>-gallery-1.webp" .. -5
  faqs: { q: string, a: string }[],           // 5 practical Q&As
  bestTime: string,           // e.g. "October - April"
  idealFor: string            // e.g. "Couples, families & honeymooners"
}

Tone: aspirational but trustworthy, no hype, no hidden-fee language, concise.
Prices and details realistic for travel from India.
```
